# Speccadex – Backend

A Speccadex közös backendje, amelyet a webes, az asztali és a mobil alkalmazás is használ.

## Tech stack
- NestJS (Node.js / TypeScript)
- Prisma ORM
- PostgreSQL
- Swagger / OpenAPI dokumentáció
- JWT + Passport.js autentikáció

## Felelősök
Közös munka (Tóth Kristóf Antal, Vincze Dominik, Papp-hegyi Ákos). Az adatbázis és a backend tervezése közösen történik.

## Kapcsolódó repók
- speccadex-web
- speccadex-desktop
- speccadex-mobile

## Státusz
Tervezés alatt. Az adatbázis-séma véglegesítése folyamatban van.
